# ぷらっと東海 ホームのカード用 絵の注文文

3枚とも、下の「共通」を先に入れてから、各場面の文を足す。

## 共通

```
やわらかい水彩風のアニメイラスト。縦長に近い正方形(横10:縦11)。
3人(1人と2匹)を同じ絵に入れる。
- 女の子:茶色の長い髪(片側に細い三つ編み)、紺のブレザー、赤いリボン、白いシャツ、紺のプリーツスカート、茶色のローファー。明るい笑顔。
- 猫:キジトラ、口元・胸・足が白、赤い首輪に金色の鈴。
- 柴犬:赤茶と白、赤い首輪に金色の鈴、笑顔。
絵の中に文字・看板・ロゴを入れない。
カードの下のほうに猫と柴犬、まん中に女の子。上のほうは景色。
```

## ドライブ

```
海ぞいのカーブした道を見わたす展望駐車場。青い海と青空。
女の子は車の横で、のびをしながら景色をながめる。
猫は車のボンネットの上にすわり、柴犬は女の子の足元でしっぽをふる。
車は白い小さな車。運転席は写さない。
```

## 温泉

```
温泉街の屋根つきの足湯。木の湯船から湯気が上がる。
女の子は制服のまま、くつ下をぬいで足だけ湯に入れ、にっこり。
猫はとなりの木のベンチで丸くなり、柴犬は足湯のふちで湯気をくんくんかぐ。
うしろに、のれんと石畳の温泉街。
```

## 不動産

```
高台から見下ろす、緑の多い住宅街の町並み。
女の子は町の地図を広げて、どの町がいいか指さして考えている。
猫は女の子の肩ごしに地図をのぞきこみ、柴犬は小さな家の模型のとなりにおすわり。
```
