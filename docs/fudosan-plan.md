# ぷらっと不動産 で扱う内容の案

> この文書は「案」です。まだページやデータは作っていません。
> 章平さんが東海地方(愛知・岐阜・三重・静岡)に **平屋** を建てる場合を想定して、
> 「ぷらっと不動産」に載せると役に立ちそうな内容をまとめました。
> 実在の不動産会社・ハウスメーカー・物件の宣伝はしません。

## 1. ページの考え方

- ほかのページと同じく、**1画面に収まる**ように短くまとめる
- 「県 → 市町村」と選ぶと、その地域の **平屋の建てやすさ** がひと目で分かる形にする
- 口コミ・点数・ランキングは入れない
- 値段など変わりやすい数字は、**公的な出典(国や県の公表データ)と確認した日付** をいっしょに書く

## 2. 地域ごとに載せる項目(案)

1つの市町村につき、次のような短いカードにする想定です。

| 項目 | 中身の例 | 主な出典 |
|---|---|---|
| 土地の値段の目安 | 住宅地の公示地価・基準地価(1㎡あたり/1坪あたり) | 国土交通省「不動産情報ライブラリ」、各県の地価調査 |
| 広い土地の探しやすさ | 郊外・田園地域が多いか(平屋は土地が広めに必要) | 市町村の都市計画 |
| 災害への備え | 洪水・土砂・津波・地震の想定があるか | 国土交通省「ハザードマップポータルサイト」、市町村のハザードマップ |
| 暮らしの便利さ | 駅・スーパー・病院・学校までの距離感 | 市町村の公式情報 |
| 気候のくせ | 夏の暑さ、雪の多さ(岐阜の飛騨など)、海風・塩害(沿岸部) | 気象庁 |
| 補助制度 | 移住・住宅取得・省エネ住宅の補助があるか | 市町村・県の公式サイト |

## 3. おすすめ地域の選び方(考え方の案)

特定の地域を「ここが一番」と決めつけず、**暮らし方の型** で見られるようにします。

- **名古屋に通いながら平屋** … 尾張・西三河の郊外(鉄道沿線の駅から少し離れた地域)。土地代は高めなので、敷地の広さとのバランスを見る
- **ゆったり広い土地で平屋** … 東三河、岐阜の西濃・中濃、三重の中南勢など。土地は手ごろなことが多いが、車が必須
- **海の近くで平屋** … 知多半島、渥美半島、三重・静岡の沿岸。景色はよいが、**津波・高潮の想定** と塩害対策を必ず確認
- **山あい・高原で平屋** … 飛騨・東濃・奥三河など。雪・寒さへの備え(断熱・屋根の形)と冬の道路事情を確認

## 4. 平屋の建て方(基本のまとめ案)

- **平屋のよいところ**: 階段がなく年を重ねても暮らしやすい/家族の気配が分かりやすい/地震の揺れに比べて有利になりやすい/外壁の点検・修理がしやすい
- **気をつけるところ**: 同じ広さの2階建てより **広い土地と、基礎・屋根の面積** が必要/建物の真ん中が暗くなりやすい(中庭・天窓などで工夫)/周りに2階建てが多いと日当たり・目線が気になる
- **間取りの考え方**: 廊下を短くする、L字・コの字にして中庭をつくる、収納は屋根裏や小屋裏も検討
- **性能**: 断熱・耐震の等級、東海は夏の暑さ対策(日よけ・風通し)も大事

## 5. 土地選びの目安(案)

- **広さの目安**: 平屋の床面積+駐車場2〜3台分+庭。目安として、建てたい家の床面積のおよそ2倍以上の土地があると余裕が出やすい(建ぺい率で変わる)
- **建ぺい率・用途地域**: 建ぺい率が低い地域ほど広い土地が必要。市町村の都市計画図で確認
- **市街化調整区域**: 原則として家を建てにくい区域。土地が安くても、建てられるか必ず確認
- **災害**: ハザードマップで浸水・土砂・津波を確認。土地の高さ(周りより低くないか)も見る
- **インフラ**: 上下水道・ガスが来ているか(引き込みに費用がかかることがある)
- **道路**: 建築基準法上の道路に2m以上接しているか

## 6. 費用の考え方(案)

具体的な金額は時期・地域・仕様で大きく変わるため、ページでは **「何にお金がかかるか」** を中心に説明し、数字は出典つきの目安にとどめます。

- **土地代** … 地価の公表データで目安をつかむ。仲介手数料・登記費用も別にかかる
- **建物の本体工事費** … 平屋は基礎・屋根が広いぶん、同じ床面積の2階建てより坪あたりの単価が高めになりやすい
- **付帯工事費** … 地盤改良、外構(駐車場・塀)、上下水道の引き込みなど
- **諸費用** … 住宅ローンの手数料、火災保険・地震保険、税金(不動産取得税・固定資産税)など
- **入居後の費用** … 固定資産税、外壁・屋根のメンテナンス
- **補助・減税** … 住宅ローン減税、省エネ住宅の補助、市町村の補助(年度ごとに内容が変わるので最新を確認)
