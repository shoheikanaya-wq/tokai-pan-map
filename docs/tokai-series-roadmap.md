# 東海シリーズ ロードマップ

## 目的
東海ウォーカー型の情報集約を単純に模倣するのではなく、生成AI・地理空間AI・AIエージェント等を活用した「未来型地域インテリジェンス」を育てる。

## 現在の優先順位
1. 東海パンMAPを実証基盤として完成度を上げる
2. パンMAPで確立した共通基盤を東海ラーメンへ横展開する
3. パン・ラーメン以外へ拡張可能な共通データモデルとUIを整える
4. 未来技術を継続的に探索し、実装可能になったものから取り込む

## 共通基盤候補
- 店舗・地域・イベントの共通データモデル
- 検索・ランキング
- 地理空間処理
- PWA/UI
- 行動・ルート生成
- 分析
- AIエージェント連携

## 未来技術レーダー
継続調査対象:
- World Model
- 4D地域地図
- 地域デジタルツイン
- 地理空間AI
- 予測型検索
- AIエージェント
- 行動生成
- オンデバイスAI
- XR/AR
- センサー連携

採用判断では「名称が新しいか」ではなく、現在利用可能か、実証段階か、将来仮説かを区別し、東海シリーズへ実際に組み込める価値があるかを確認する。

## 運用
- 毎朝8時の「東海シリーズ自動開発」で1段階前進させる。
- 調査だけで終了せず、可能なら実装・テスト・設計成果・監査改善・再利用資産のいずれかを完成させる。
- ユーザーは細かな操作を担当せず、必要な場合だけ最終確認する。
- 新規課金、認証/IAM権限拡大、APIキー・秘密情報、公開範囲拡大、重大なセキュリティ変更、データ削除、新規外部サービス契約は要承認。
- 完了成果、検証結果、再利用資産、未完了理由、次の一手、未来技術レーダーの有用な発見を簡潔に残す。

## 開発思想
「AIをユーザーが毎日操作する」のではなく、「AI群が裏側で調査・設計・実装を進め、ユーザーは重要な判断と最終確認だけを行う」。
