# PAN 管理者機能・セキュリティ実装ゲート

## 現状（2026-09-29）
- 一般画面には管理者リンクを表示しない。フッター5回タップで開く既存PINは誤操作防止のみであり、認証ではない。
- 管理画面の「利用状況」は自端末のデータ項目を確認する**プレビュー**。他の利用者の訪問は記録・取得していない。
- 既存Cloud Run route-api は経路計算のみ。メモリ/ローカルファイルを訪問履歴の永続保存に使わない。
- 匿名端末IDは初回プレビュー時にブラウザlocalStorageへ作成する。ブラウザ削除・再インストールで変わり得る。個人の識別・追跡に使わない。

## 本番足あと機能を有効化する条件（未実施）
1. 管理者ログインはサーバー側で検証する。クライアントPIN/隠し入口/ブラウザlocalStorageを認証に使わない。
2. 認証済み管理者以外は一覧APIへアクセスできないことを自動テストする（401/403）。
3. 訪問データは保存先・保持期間・削除方法・公開プライバシー説明を決定し、必要な同意・告知を実装してから収集開始する。
4. 保存は必要最小限（JSTアクセス時刻、ランダム匿名ID、初回/最終、回数、OS、ブラウザ、端末区分、取得可能な機種、起動ページ、アプリ版）。名前・電話・メール・GPS・正確な位置・強い指紋を収集しない。IPを独自保存しない。
5. 書込APIにも入力検証、サイズ制限、レート制限、濫用対策を実装。Origin/CORSだけを認証とみなさない。
6. 管理セッションは短寿命、HttpOnly/Secure/SameSite Cookieなど適切な方式で管理し、ログアウト・失効・総当たり防止を備える。
7. Cloud保存の新規有効化・課金・IAM・認証/シークレット変更が必要なら【要承認】。承認前に有効化しない。

## セキュリティ監査
- XSS: 動的HTMLのエスケープ、ユーザー文字列のtextContent使用を確認。
- 外部リンク: https、noopener/noreferrer、URL許可リスト。
- API: 認証/認可、入力検証、ログに秘密情報が残らないこと。
- ブラウザ: CSP、HTTPS、Service Worker更新整合性、依存ライブラリ更新。
- 端末のウイルス検出機能はPWAでは提供しない。OS/ブラウザの保護機能を利用する。
