# ぷらっとパン：ホームA/D切替（採用仕様）

- スマホ表示を最優先。既存の機能・市町村ボタン・パンラッシュの操作は維持。
- 起動時にA（シンプル・バランス）またはD（元気・走るシーン）のビジュアルをランダムに選択。画面内の操作要素は両方共通。
- 現行正式画像 `tokai-pan-home (1).png` は削除しない。A/D素材の個別画像がGitHubに揃い、実機で確認できるまで現在の公開画像を維持する。
- B/C/E/Fのデザインはホームに採用せず、キャラ画像部分を別ページへ再利用する候補。既存画像を上書きしない。
- 愛知・岐阜・三重のTOP10は各県名横にコンパクトなボタン。地図から探す機能は追加しない。
- パンラッシュなどは既存ボタンを維持し、リンク先で原点画像を活用。
- 既存の余白にのみミニキャラを配置し、スクロール増加や操作要素への重なりを避ける。

## 実装待ち
A/D各ビジュアルを独立した画像ファイルとしてアップロード後、画像切替とPWAキャッシュ更新を行う。比較シート全体をそのままホーム画像にしない。
